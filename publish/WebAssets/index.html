MarkdownViewer

轻量 Markdown 阅读与编辑器（WebView2 + markdown-it + CodeMirror）

  • 点击工具栏「打开文件」或直接把 .md 文件拖入窗口
  • 左侧自动生成 H1~H6 目录，点击跳转，滚动时自动高亮
  • 工具栏切换「预览 / 分栏 / 编辑」；编辑模式下 Ctrl+S 保存
  • 支持命令行参数：MarkdownViewer.exe 文档.md
  • 支持 GFM 表格、任务列表、代码块、相对路径图片
  • 点击表格或图表右上角「编辑」（也可双击）打开可视化编辑器
  • 菜单「帮助 → 关于 MarkdownViewer」可查看版本、作者与开源协议
  • Ctrl+F 查找 / 替换，Ctrl+滚轮 或 Ctrl+= 缩放
  • 工具栏可导出 PDF / HTML、打印，粘贴图片自动保存到 assets
